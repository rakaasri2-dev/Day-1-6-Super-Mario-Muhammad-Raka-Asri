# 💻 SESI 1 – BUILDING WITH AI, MANAGING CHANGE WITH GITHUB

**Pemateri: Nugi Farhan**

Sesi pertama membahas pemanfaatan Artificial Intelligence dalam proses pengembangan aplikasi serta penggunaan Git dan GitHub untuk mengelola perubahan proyek.

## 1. Prompt Engineering

### 1.1 Pengertian Prompt

Prompt merupakan instruksi atau masukan yang diberikan kepada model AI untuk mendapatkan hasil tertentu. Bentuknya dapat berupa pertanyaan sederhana, kata kunci, instruksi kompleks, maupun potongan kode.

**Prompt Engineering** adalah proses menyusun dan mengoptimalkan instruksi agar AI dapat memberikan respons yang lebih relevan dan sesuai dengan kebutuhan pengguna.

### 1.2 Pentingnya Context dalam Prompt

Context atau konteks merupakan informasi tambahan yang diberikan kepada AI agar model dapat memahami tujuan dan kebutuhan dari instruksi.

Pemberian konteks yang jelas membantu AI menghasilkan jawaban yang lebih terarah dibandingkan instruksi yang terlalu umum.

Contohnya, ketika meminta AI membuat aplikasi, pengguna sebaiknya menjelaskan tujuan aplikasi, target pengguna, fitur yang diperlukan, serta teknologi yang ingin digunakan.

### 1.3 Struktur Prompt yang Baik

Dalam materi workshop, struktur prompt terdiri dari empat komponen:

| Komponen | Penjelasan |
|---|---|
| Role | Menentukan peran yang harus dijalankan oleh AI. |
| Task | Menjelaskan pekerjaan yang harus dilakukan. |
| Context | Memberikan informasi dan latar belakang kebutuhan. |
| Format | Menentukan bentuk hasil yang diharapkan. |

### 1.4 Contoh Penerapan Prompt

Materi workshop memberikan contoh pembuatan aplikasi **Student Task Planner**, yaitu aplikasi web sederhana yang dirancang untuk membantu mahasiswa mengelola tugas kuliah dan tenggat waktu.

Fitur yang direncanakan meliputi:

- Menampilkan daftar tugas atau assignment.
- Menampilkan judul tugas dan tanggal tenggat.
- Menampilkan status penyelesaian tugas.
- Menandai tugas sebagai selesai.
- Menyediakan filter All, Pending, dan Completed.

Batasan teknis yang dicontohkan:

- Menggunakan HTML, CSS, dan JavaScript murni (Vanilla JavaScript).
- Tidak menggunakan framework atau dependensi eksternal yang tidak diperlukan.
- Menggunakan struktur kode yang terorganisasi.
- Menyediakan kode lengkap dan cara menjalankan aplikasi.
- Menyertakan cara menguji fitur-fitur utama.

### 1.5 Keuntungan Prompt Engineering

Beberapa keuntungan Prompt Engineering yang dibahas dalam materi:

1. Meningkatkan performa model AI.
2. Mengurangi bias dan respons yang bersifat ofensif.
3. Meningkatkan kontrol dan prediktabilitas hasil AI.
4. Memberikan pengalaman penggunaan AI yang lebih baik.

## 2. Pengenalan Git dan GitHub

### 2.1 Git

Git adalah sistem version control terdistribusi (Distributed Version Control System/DVCS) yang digunakan untuk melacak dan mengelola perubahan pada file dalam sebuah proyek.

Git memungkinkan pengguna menyimpan riwayat perubahan, mengetahui perkembangan proyek, serta mengelola berbagai versi pekerjaan.

Git dikembangkan oleh Linus Torvalds pada tahun 2005.

### 2.2 GitHub

GitHub adalah platform berbasis web yang digunakan untuk menyimpan repository Git secara online serta mendukung kolaborasi dalam pengembangan perangkat lunak.

GitHub menyediakan fasilitas untuk mengelola proyek, menyimpan kode, dan bekerja sama dengan pengembang lainnya.

### 2.3 Perbedaan Git dan GitHub

| Git | GitHub |
|---|---|
| Sistem version control. | Platform penyimpanan repository berbasis web. |
| Melacak perubahan file. | Menyimpan repository Git secara online. |
| Dapat digunakan secara lokal. | Mendukung kolaborasi secara online. |
| Mengelola riwayat perubahan. | Menyediakan fitur seperti Issues dan Pull Requests. |

**Kesimpulan:** Git digunakan untuk mengelola versi proyek, sedangkan GitHub menyediakan platform untuk menyimpan repository Git dan mendukung kolaborasi.

## 3. Git Workflow

Git memiliki tiga bagian utama dalam pengelolaan perubahan.

### 3.1 Working Directory

Working Directory merupakan tempat pengguna membuat, melihat, dan mengubah file proyek.

### 3.2 Staging Area

Staging Area merupakan tempat untuk menyiapkan perubahan yang akan dimasukkan ke dalam commit berikutnya.

Pengguna dapat memilih perubahan tertentu sebelum menyimpannya ke dalam riwayat repository.

### 3.3 Git Directory

Git Directory merupakan tempat Git menyimpan metadata dan object database yang diperlukan untuk mengelola repository, termasuk riwayat perubahan.

### 3.4 Alur Kerja Git

```text
Working Directory
       |
       | git add
       v
  Staging Area
       |
       | git commit
       v
 Local Repository
       |
       | git push
       v
Remote Repository
    (GitHub)
```

Alur tersebut menggambarkan proses perubahan file, persiapan perubahan, penyimpanan commit, hingga pengiriman perubahan ke repository remote.

## 4. Perintah Dasar Git

### 4.1 Inisialisasi Repository

```bash
git init
```

Membuat repository Git baru pada direktori yang sedang digunakan.

### 4.2 Menambahkan Perubahan

```bash
git add .
```

Menambahkan perubahan pada direktori saat ini beserta subdirektorinya ke Staging Area.

```bash
git add -A
```

Menambahkan seluruh perubahan dalam repository, termasuk file baru, perubahan file, dan penghapusan file.

```bash
git add --all
```

Memiliki fungsi yang sama dengan `git add -A`.

```bash
git add *
```

Menggunakan wildcard yang diperluas oleh shell untuk memilih file. Perilakunya dapat berbeda dari `git add -A`, terutama untuk file tersembunyi dan file yang dihapus.

### 4.3 Menyimpan Perubahan

```bash
git commit -m "Initial commit"
```

Menyimpan perubahan yang telah berada di Staging Area ke dalam riwayat repository lokal.

### 4.4 Menghubungkan Repository Remote

```bash
git remote add origin <URL-REPOSITORY>
```

Menambahkan alamat repository remote dengan nama `origin`.

### 4.5 Mengirim Perubahan ke GitHub

```bash
git push origin main
```

Mengirim commit dari branch lokal `main` ke branch `main` pada repository remote bernama `origin`.

### 4.6 Mengambil Perubahan dari GitHub

```bash
git pull origin main
```

Mengambil perubahan dari branch `main` pada remote `origin` dan mengintegrasikannya ke branch lokal yang sedang digunakan.

Git pull pada dasarnya menjalankan proses fetch kemudian merge.

## 5. Persiapan Lingkungan Pengembangan

### 5.1 Instalasi dan Pemeriksaan Git

Untuk memeriksa apakah Git telah terinstal:

```bash
git --version
```

### 5.2 Konfigurasi Identitas Git

Mengatur nama pengguna:

```bash
git config --global user.name "Your Name"
```

Mengatur email:

```bash
git config --global user.email "your-email@example.com"
```

Memeriksa konfigurasi:

```bash
git config --global --list
```

Nama dan email tersebut digunakan sebagai identitas penulis pada commit.

### 5.3 Visual Studio Code

Visual Studio Code merupakan code editor yang dapat digunakan untuk mengembangkan dan mengelola file proyek.

Pemeriksaan versi VS Code melalui terminal:

```bash
code --version
```

Perintah ini dapat digunakan apabila perintah `code` telah tersedia pada PATH sistem.

## 6. Menghubungkan Repository dengan GitHub

Repository lokal dapat dihubungkan dengan GitHub melalui dua pendekatan.

**Menggunakan git init:**

1. Membuat repository baru di direktori lokal.
2. Menjalankan `git init`.
3. Menambahkan perubahan dengan `git add`.
4. Menyimpan perubahan dengan `git commit`.
5. Menghubungkan repository dengan GitHub menggunakan `git remote add`.
6. Mengirim perubahan menggunakan `git push`.

**Menggunakan git clone:**

```bash
git clone <URL-REPOSITORY>
```

Perintah ini digunakan untuk menyalin repository yang sudah tersedia di GitHub ke komputer lokal, termasuk riwayat Git yang tersedia.

## 7. SSH Key dan Koneksi GitHub

### 7.1 Pengertian SSH

SSH (Secure Shell) merupakan protokol komunikasi aman yang dapat digunakan untuk mengautentikasi koneksi antara komputer lokal dan GitHub.

SSH Key terdiri dari dua bagian:

- **Public Key:** Kunci publik yang dapat ditambahkan ke akun GitHub.
- **Private Key:** Kunci privat yang disimpan secara aman di komputer pengguna dan tidak boleh dibagikan.

### 7.2 Membuat SSH Key

Materi workshop memperkenalkan algoritma Ed25519 untuk membuat SSH Key.

```bash
ssh-keygen -t ed25519 -C "email@domain.com"
```

Pengguna dapat menentukan lokasi penyimpanan dan passphrase ketika proses pembuatan SSH Key berlangsung.

### 7.3 Menghubungkan SSH Key dengan GitHub

Langkah umumnya:

1. Membuat pasangan SSH Key.
2. Menyimpan private key pada komputer lokal.
3. Mengambil isi public key.
4. Membuka pengaturan SSH and GPG Keys pada GitHub.
5. Memilih New SSH Key.
6. Menambahkan public key.
7. Menguji koneksi SSH.

Perintah untuk menguji koneksi:

```bash
ssh -T git@github.com
```

Jika autentikasi berhasil, GitHub akan memberikan pesan bahwa pengguna telah berhasil diautentikasi.

**Catatan:** Beberapa perintah pengelolaan SSH agent dan Keychain pada materi workshop secara khusus menggunakan macOS. Langkah konfigurasi dapat berbeda pada Windows dan Linux.

## 8. Penerapan AI dalam Pengembangan Aplikasi

Materi workshop memperkenalkan penggunaan platform AI-assisted untuk membantu proses pengembangan aplikasi.

Contoh platform yang disebutkan:

- Claude
- Antigravity
- ChatGPT

### 8.1 Student Task Planner

Student Task Planner merupakan contoh aplikasi web sederhana yang direncanakan untuk membantu mahasiswa mengelola tugas kuliah.

Fitur yang direncanakan meliputi daftar tugas, tanggal tenggat, status penyelesaian, serta filter berdasarkan status tugas.

### 8.2 Alur Pengembangan

1. Menginstal platform AI-assisted.
2. Menyusun prompt untuk membuat aplikasi.
3. Membuat repository Git lokal menggunakan `git init`.
4. Menyimpan perubahan dengan `git commit`.

7. Melakukan commit dan push kembali untuk menyimpan pembaruan.

# 🎓 SESI 2 – KURIKULUM MERDEKA DI PERGURUAN TINGGI

**Materi: Merdeka Belajar – Kampus Merdeka (MBKM & MSIB)**

Sesi kedua membahas kebijakan Merdeka Belajar – Kampus Merdeka, program Magang dan Studi Independen Bersertifikat, serta metode pembelajaran yang mendukung pengembangan kompetensi mahasiswa.

## 1. Pengertian MBKM

Merdeka Belajar – Kampus Merdeka (MBKM) merupakan kebijakan pendidikan tinggi yang diperkenalkan oleh Kemendikbudristek sejak tahun 2020.

Kebijakan ini memberikan kesempatan kepada mahasiswa untuk mengembangkan kemampuan sesuai minat dan bakat, termasuk memperoleh pengalaman belajar di luar lingkungan program studi maupun terjun langsung ke dunia kerja.

### Tujuan MBKM

- Mempersiapkan lulusan agar lebih siap menghadapi dunia kerja.
- Memberikan fleksibilitas dalam proses pembelajaran.
- Menghubungkan pembelajaran akademik dengan kebutuhan industri.
- Memberikan kesempatan belajar di luar program studi.
- Mengakui kegiatan pembelajaran tertentu melalui konversi SKS sesuai ketentuan perguruan tinggi.

## 2. Perbedaan MBKM dan MSIB

MBKM merupakan kebijakan atau kerangka pembelajaran yang memberikan kesempatan belajar lebih luas kepada mahasiswa.

Sementara itu, MSIB merupakan salah satu program yang berada dalam kerangka MBKM.

| MBKM | MSIB |
|---|---|
| Kebijakan pembelajaran yang lebih luas. | Program Magang dan Studi Independen Bersertifikat. |
| Memiliki berbagai bentuk kegiatan pembelajaran. | Berfokus pada pengalaman belajar bersama mitra industri dan organisasi. |
| Mencakup kegiatan di dalam maupun di luar lingkungan kampus. | Memiliki kegiatan magang atau pembelajaran kompetensi terstruktur. |
| Konversi SKS mengikuti ketentuan program studi. | Dalam skema yang dijelaskan, berlangsung satu semester dan dapat dikonversi menjadi SKS. |

## 3. Delapan Bentuk Kegiatan Pembelajaran MBKM

Materi workshop menjelaskan delapan bentuk kegiatan pembelajaran MBKM.

| No. | Kegiatan | Penjelasan |
|---|---|---|
| 1 | Pertukaran Pelajar | Belajar di program studi atau perguruan tinggi lain. |
| 2 | Magang / Praktik Kerja | Mendapatkan pengalaman langsung di dunia industri. |
| 3 | Asistensi Mengajar | Membantu proses pembelajaran di satuan pendidikan. |
| 4 | Penelitian / Riset | Melakukan penelitian bersama dosen atau lembaga riset. |
| 5 | Proyek Kemanusiaan | Berpartisipasi dalam kegiatan kemanusiaan. |
| 6 | Kegiatan Wirausaha | Merintis dan mengembangkan usaha. |
| 7 | Proyek Independen | Mengembangkan proyek atau inovasi secara mandiri. |
| 8 | Membangun Desa / KKN | Melaksanakan kegiatan pengabdian masyarakat di desa. |

## 4. Hak Belajar dan Konversi SKS

Dalam materi presentasi, MBKM dijelaskan memberikan kesempatan kepada mahasiswa untuk mengikuti kegiatan pembelajaran di luar program studi.

Skema yang diilustrasikan mencakup:

- Satu semester belajar di luar program studi dalam perguruan tinggi yang sama.
- Satu semester belajar di luar kampus, misalnya melalui kegiatan magang di industri.
- Konversi SKS ditetapkan oleh program studi bersama dosen pembimbing.

Konversi SKS bukan berarti semua kegiatan otomatis memperoleh jumlah SKS yang sama. Pengakuannya mengikuti kesesuaian kegiatan, ketentuan akademik, dan kebijakan program studi.

**Catatan ketelitian:** Materi presentasi menyebut angka dua semester pada bagian utama, tetapi slide penutup menyebut tiga semester. Karena terdapat perbedaan internal dalam presentasi, jumlah hak belajar di luar program studi perlu dikonfirmasi melalui pedoman akademik dan ketentuan resmi yang berlaku di perguruan tinggi.

## 5. MSIB – Magang dan Studi Independen Bersertifikat

MSIB merupakan salah satu program unggulan yang dibahas dalam materi MBKM.

Program ini terdiri dari dua bentuk utama:

### 5.1 Magang Bersertifikat

Magang Bersertifikat memberikan kesempatan kepada mahasiswa untuk belajar sambil bekerja di perusahaan atau organisasi mitra.

Kegiatan yang dilakukan antara lain:

- Mengerjakan tugas dan proyek nyata.
- Memperoleh pengalaman kerja langsung.
- Mendapatkan bimbingan dari mentor industri.
- Mengembangkan kompetensi sesuai kebutuhan dunia kerja.

### 5.2 Studi Independen Bersertifikat

Studi Independen Bersertifikat memberikan kesempatan kepada mahasiswa untuk mempelajari kompetensi tertentu melalui pembelajaran terstruktur bersama pakar atau mitra industri.

Bentuk kegiatan dapat berupa:

- Short course.
- Bootcamp.
- Massive Open Online Course (MOOC).
- Proyek dan studi kasus bersama peserta maupun mitra.

### 5.3 Persamaan Kedua Program

Berdasarkan skema yang dijelaskan dalam presentasi, kedua program memiliki beberapa kesamaan:

- Berlangsung selama satu semester.
- Dapat dikonversi menjadi 20 SKS sesuai skema dan ketentuan program.
- Memberikan sertifikat.
- Memberikan peluang rekomendasi kepada mitra.

## 6. Metode Pembelajaran

Materi workshop menjelaskan tiga pendekatan pembelajaran yang mendorong mahasiswa menjadi lebih aktif.

### 6.1 Project-Based Learning (PjBL)

Project-Based Learning merupakan metode pembelajaran yang berfokus pada pengerjaan proyek nyata dalam jangka waktu tertentu.

Umumnya, proyek dilakukan secara individu maupun kelompok dan menghasilkan sesuatu yang dapat dipresentasikan.

Contoh hasil proyek:

- Produk.
- Prototipe.
- Aplikasi.
- Laporan proyek.

Metode ini sesuai dengan pendidikan vokasi karena mendorong mahasiswa untuk menerapkan pengetahuan melalui karya nyata.

### 6.2 Problem-Based Learning (PBL)

Problem-Based Learning merupakan metode pembelajaran yang dimulai dari suatu permasalahan nyata yang perlu dianalisis dan diselesaikan.

Dalam metode ini:

1. Mahasiswa mengidentifikasi permasalahan.
2. Mahasiswa mencari informasi yang relevan.
3. Mahasiswa menganalisis penyebab masalah.
4. Mahasiswa merumuskan solusi.
5. Dosen berperan sebagai fasilitator pembelajaran.

### 6.3 Case-Based Learning (CBL)

Case-Based Learning merupakan metode pembelajaran yang menggunakan kasus nyata sebagai bahan analisis dan diskusi.

Tahapan pembelajarannya:

1. **Pelajari kasus:** Membaca kasus dari industri atau masyarakat.
2. **Identifikasi masalah:** Menentukan inti persoalan dan data yang relevan.
3. **Analisis dan diskusi:** Membahas kasus dari berbagai sudut pandang.
4. **Rumuskan solusi:** Menyusun rekomendasi beserta alasan dan risikonya.
5. **Presentasi dan refleksi:** Menyampaikan hasil dan mengevaluasi pembelajaran.

### 6.4 Perbedaan PjBL, PBL, dan CBL

| Metode | Fokus Utama | Hasil Pembelajaran |
|---|---|---|
| PjBL | Pengerjaan proyek nyata. | Produk, prototipe, atau aplikasi. |
| PBL | Pemecahan masalah terbuka. | Solusi berdasarkan analisis. |
| CBL | Analisis kasus yang telah tersedia. | Kesimpulan dan rekomendasi solusi. |

Ketiganya mendorong mahasiswa untuk aktif, bekerja sama, berpikir kritis, dan menghadapi permasalahan nyata.

## 7. Manfaat MBKM bagi Mahasiswa Politeknik

Pendidikan politeknik memiliki fokus pada keterampilan terapan. MBKM dan MSIB dapat memperkuat hubungan antara pembelajaran di kampus dengan kebutuhan industri.

Beberapa manfaatnya:

1. **Pengalaman kerja nyata:** Memberikan kesempatan untuk mengenal lingkungan kerja sebelum lulus.
2. **Kompetensi relevan:** Mengembangkan keterampilan yang sesuai dengan kebutuhan dunia kerja.
3. **Jejaring profesional:** Memperluas hubungan dengan mentor, praktisi, dan peserta lainnya.
4. **Sertifikat dan SKS:** Memberikan pengakuan terhadap pengalaman belajar sesuai ketentuan akademik.

## 8. Alur Mengikuti Program Kampus Merdeka

Materi workshop menjelaskan tahapan umum untuk mengikuti program:

1. **Cek data PDDikti:** Memastikan data diri sesuai dengan data akademik.
2. **Buat akun:** Mendaftarkan akun pada portal program yang tersedia.
3. **Pilih program:** Mencari program magang atau studi independen yang sesuai.
4. **Daftar dan seleksi:** Melengkapi dokumen dan mengikuti proses seleksi.
5. **Jalani program dan konversi SKS:** Mengikuti kegiatan, memperoleh sertifikat, dan mengajukan pengakuan akademik kepada program studi.

Sebelum mendaftar, mahasiswa disarankan berkonsultasi dengan koordinator MBKM atau dosen pembimbing akademik.

## 9. Tips Mengikuti MBKM dan MSIB

Beberapa hal yang perlu dipersiapkan:

- Mengenali minat dan arah karier.
- Memilih program yang sesuai dengan program studi.
- Berkonsultasi dengan dosen mengenai rencana dan konversi SKS.
- Menyiapkan CV dan portofolio.
- Memastikan data akademik dan administrasi lengkap.
- Disiplin dalam mengikuti kegiatan.
- Mendokumentasikan aktivitas sebagai bahan laporan.

Ketentuan, kuota, dan mitra program dapat berubah setiap periode. Oleh karena itu, mahasiswa perlu memeriksa informasi resmi sebelum mendaftar.

**Jabatan: Kepala Program Studi Teknik Informatika (D4), Politeknik Negeri Jakarta**

Sesi ketiga membahas Kurikulum Outcome-Based Education (OBE) 2026 pada Program Studi D4 Teknik Informatika Politeknik Negeri Jakarta.

Pembahasan mencakup profil lulusan, profesi yang relevan dengan kebutuhan industri, Capaian Pembelajaran Lulusan (CPL), struktur mata kuliah, serta strategi belajar yang efektif.

## 1. Pengertian Outcome-Based Education (OBE)

Outcome-Based Education (OBE) merupakan pendekatan pendidikan yang berfokus pada hasil pembelajaran atau kompetensi yang harus dimiliki oleh lulusan.

Dalam kurikulum OBE, penyusunan kurikulum dimulai dari kompetensi dan profil lulusan yang ingin dicapai, kemudian diturunkan menjadi Capaian Pembelajaran Lulusan (CPL) dan mata kuliah yang mendukung pencapaian tersebut.

Berdasarkan presentasi Kurikulum OBE 2026 D4 Teknik Informatika PNJ:

| Komponen | Jumlah |
|---|---:|
| Semester | 8 |
| Mata Kuliah | 49 |
| Total Beban Studi | 145 SKS |
| Profil Lulusan | 4 |
| Capaian Pembelajaran Lulusan | 11 |

Lulusan program ini memperoleh gelar Sarjana Terapan Komputer (S.Tr.Kom.) dengan kualifikasi KKNI Level 6.

### 1.1 Alur Penyusunan Kurikulum

Kurikulum disusun secara bertahap:

1. **Profil Lulusan:** Menentukan peran dan kemampuan yang diharapkan dimiliki lulusan.
2. **Profesi:** Mengidentifikasi bidang pekerjaan yang relevan berdasarkan kebutuhan industri.
3. **CPL:** Menentukan kompetensi yang harus dicapai mahasiswa.
4. **Mata Kuliah:** Menyusun mata kuliah untuk mendukung pencapaian kompetensi tersebut.

## 2. Empat Profil Lulusan

Kurikulum OBE 2026 menetapkan empat profil lulusan utama.

### 2.1 PL01 – Analis Solusi

Mampu menganalisis permasalahan nyata dan merumuskan solusi komputasi.

Contoh profesi:

- System Analyst.
- Business Analyst IT.
- IT Consultant Junior.
- Solution Analyst.

### 2.2 PL02 – Pengembang Aplikasi

Mampu merancang, membangun, menguji, dan mengevaluasi aplikasi.

Contoh profesi:

- Software Developer.
- Web Developer.
- Mobile Application Developer.
- Software Quality Assurance.
- UI/UX Developer.

### 2.3 PL03 – Penerap Teknologi

Mampu menerapkan teknologi data, Artificial Intelligence, jaringan, cloud, dan keamanan siber.

Contoh profesi:

- Data Analyst Junior.
- AI/ML Engineer Junior.
- Cloud Engineer Junior.
- Network Administrator.
- Cybersecurity Analyst Junior.

### 2.4 PL04 – Profesional Kolaboratif

Mampu bekerja secara etis, komunikatif, kolaboratif, dan adaptif dalam lingkungan profesional.

Contoh profesi:

- IT Project Officer.
- IT Support Specialist.
- Technical Writer.
- Scrum Team Member.
- Technopreneur.

## 4. Capaian Pembelajaran Lulusan (CPL)

Capaian Pembelajaran Lulusan (CPL) merupakan kompetensi yang diharapkan dapat dikuasai mahasiswa setelah menyelesaikan pendidikan.

Kurikulum OBE 2026 D4 Teknik Informatika memiliki sebelas CPL.

| Kode | Capaian Pembelajaran |
|---|---|
| CPL 01 | Bertakwa, taat hukum, disiplin, dan bertanggung jawab. |
| CPL 02 | Memiliki sikap profesional dan etis, termasuk dalam keamanan informasi. |
| CPL 03 | Memahami sistem komputer serta menerapkan algoritma dan metode komputasi. |
| CPL 04 | Menganalisis persoalan komputasi kompleks dan merancang solusi TI. |
| CPL 05 | Merancang dan mensimulasikan aplikasi multi-platform. |
| CPL 06 | Berkomunikasi dan melakukan presentasi secara efektif, bekerja sama, serta memimpin tim multidisiplin. |
| CPL 07 | Menyusun laporan dan artikel ilmiah. |
| CPL 08 | Mengimplementasikan kebutuhan komputasi dengan metode yang sesuai. |
| CPL 09 | Merancang dan mengevaluasi antarmuka serta User Experience (UX). |
| CPL 10 | Menerapkan metode analitis secara sistematis dan terukur. |
| CPL 11 | Mengembangkan dan mengevaluasi solusi komputasi multi-platform. |

## 7. Strategi Belajar yang Efektif

Selain membahas kurikulum, materi workshop juga menjelaskan pentingnya metode belajar yang efektif berdasarkan penelitian ilmu kognitif.

Materi ini merujuk pada buku *Make It Stick: The Science of Successful Learning* karya Peter C. Brown, Henry L. Roediger III, dan Mark A. McDaniel (2014).

### 7.1 Empat Mitos tentang Belajar

**Mitos 1: Membaca ulang berkali-kali adalah cara belajar terbaik.**

Fakta: Membaca ulang dapat membuat materi terasa akrab, tetapi belum tentu menunjukkan bahwa materi sudah benar-benar dipahami. Menguji diri sendiri lebih efektif untuk mengetahui penguasaan materi.

**Mitos 2: Belajar kebut semalam sudah cukup.**

Fakta: Belajar dalam satu waktu yang terlalu padat cenderung membuat materi lebih cepat terlupakan. Pengulangan dengan jeda dapat membantu memperkuat ingatan.

**Mitos 3: Belajar yang baik harus selalu mudah dan bebas kesalahan.**

Fakta: Kesulitan yang wajar dan proses memperbaiki kesalahan dapat membantu memperkuat pemahaman dan ingatan jangka panjang.

**Mitos 4: Setiap orang memiliki satu gaya belajar tetap.**

Fakta: Materi menjelaskan bahwa bukti ilmiah tidak mendukung keharusan mencocokkan metode pembelajaran dengan label gaya belajar seperti visual atau auditori.

### 7.2 Enam Kebiasaan Belajar Efektif

Berdasarkan materi *Make It Stick*, terdapat enam kebiasaan belajar yang dapat diterapkan.

1. **Retrieval Practice (Uji Diri Sendiri)**

   Menguji ingatan dengan menutup catatan dan mencoba menjelaskan kembali materi yang telah dipelajari.

2. **Spaced Practice (Belajar Berjarak)**

   Mengulang materi dalam beberapa sesi yang memiliki jeda, bukan hanya belajar dalam satu waktu.

3. **Interleaving (Mencampur Topik)**

   Mempelajari beberapa topik secara bergantian agar terbiasa menentukan strategi yang tepat untuk setiap materi.

4. **Elaboration (Menjelaskan dengan Kata Sendiri)**

   Menghubungkan pengetahuan baru dengan pengetahuan sebelumnya dan menjelaskannya menggunakan bahasa sendiri.

5. **Generation (Mencoba Sebelum Melihat Pembahasan)**

   Mencoba menjawab pertanyaan atau menyelesaikan soal terlebih dahulu sebelum melihat penjelasan atau jawabannya.

6. **Calibration (Mengukur Pemahaman Secara Jujur)**

   Menggunakan kuis atau evaluasi untuk mengetahui tingkat pemahaman yang sebenarnya, bukan hanya mengandalkan perasaan sudah mengerti.

### 7.3 Kesimpulan Strategi Belajar

Belajar secara efektif bukan hanya tentang berapa lama seseorang membaca materi, tetapi juga bagaimana pengetahuan tersebut dilatih, diuji, dan diingat kembali.

Pengulangan dengan jeda, pengujian diri, dan kemampuan menjelaskan materi menggunakan kata sendiri dapat membantu membangun pemahaman yang lebih kuat.

# 💡 POIN PENTING DAN PENGETAHUAN BARU

Berdasarkan ketiga sesi workshop, terdapat beberapa hal penting yang dapat dirangkum.

## 1. Pemanfaatan AI dan Prompt Engineering

- AI dapat membantu proses pengembangan aplikasi apabila diberikan instruksi yang jelas.
- Prompt yang baik perlu memperhatikan role, task, context, dan format.
- Konteks yang lengkap membantu AI memahami kebutuhan pengguna.
- Hasil yang diberikan AI tetap perlu diperiksa dan dievaluasi.

## 2. Pentingnya Git dan GitHub

- Git membantu melacak dan mengelola perubahan proyek.
- GitHub menjadi tempat penyimpanan repository secara online.
- Working Directory, Staging Area, dan Git Directory memiliki fungsi berbeda.
- Commit membantu menyimpan riwayat perubahan.
- Push dan pull membantu mengelola sinkronisasi perubahan antara repository lokal dan remote.

## 3. Kesempatan Belajar Melalui MBKM

- Mahasiswa memiliki kesempatan mengembangkan kompetensi di luar pembelajaran reguler.
- MSIB memberikan pengalaman belajar melalui magang dan studi independen.
- Konversi SKS perlu mengikuti ketentuan program studi.
- Pengalaman industri dapat membantu mempersiapkan mahasiswa menghadapi dunia kerja.

## 4. Metode Pembelajaran Aktif

- Project-Based Learning berfokus pada pembuatan proyek nyata.
- Problem-Based Learning berfokus pada pemecahan masalah.
- Case-Based Learning berfokus pada analisis kasus yang tersedia.
- Ketiganya membantu mengembangkan kemampuan berpikir kritis dan kerja sama.

## 5. Pemahaman Kurikulum OBE

- Kurikulum OBE berfokus pada kompetensi yang harus dimiliki lulusan.
- Profil lulusan menjadi dasar penyusunan CPL dan mata kuliah.
- Kemampuan teknis harus didukung kemampuan komunikasi dan kolaborasi.
- Struktur mata kuliah disusun bertahap dari dasar hingga pengalaman profesional.

## 6. Pentingnya Strategi Belajar

- Membaca ulang saja belum tentu membuat seseorang benar-benar memahami materi.
- Menguji diri sendiri dapat membantu mengetahui tingkat pemahaman.
- Belajar dengan jeda membantu memperkuat ingatan.
- Menjelaskan materi dengan kata sendiri dapat memperdalam pemahaman.

# 📝 PENDAPAT DAN REFLEKSI PRIBADI

Berdasarkan rangkaian materi Day 1 Proyek Workshop 2026, saya memperoleh pemahaman bahwa proses menjadi mahasiswa di bidang teknologi informasi tidak hanya berfokus pada kemampuan menggunakan teknologi, tetapi juga mencakup cara berpikir, proses belajar, dan kesiapan menghadapi dunia kerja.

Pada sesi pertama, saya memahami bahwa Artificial Intelligence dapat dimanfaatkan sebagai alat bantu dalam pengembangan aplikasi. Namun, penggunaan AI tetap membutuhkan instruksi yang jelas dan terstruktur melalui Prompt Engineering. Selain itu, pengenalan Git dan GitHub memberikan gambaran mengenai pentingnya mengelola perubahan dan menyimpan riwayat perkembangan suatu proyek.

Pada sesi kedua, saya memperoleh wawasan mengenai MBKM dan MSIB sebagai kesempatan bagi mahasiswa untuk mengembangkan kompetensi melalui pengalaman belajar di luar lingkungan pembelajaran reguler. Materi ini memberikan pemahaman bahwa pengalaman industri, kerja sama, dan penerapan ilmu secara langsung merupakan bagian penting dalam mempersiapkan diri menghadapi dunia kerja.

Pada sesi ketiga, saya memahami bahwa Kurikulum OBE dirancang berdasarkan kompetensi yang harus dimiliki oleh lulusan. Hal yang menarik adalah bahwa kemampuan komunikasi, kerja sama, dan kepemimpinan juga menjadi bagian penting dari capaian pembelajaran. Artinya, seorang mahasiswa Teknik Informatika tidak cukup hanya menguasai kemampuan teknis, tetapi juga perlu mampu bekerja dalam tim dan menyampaikan ide dengan baik.

Selain itu, materi mengenai strategi belajar dari buku *Make It Stick* memberikan pemahaman bahwa belajar secara efektif tidak hanya dilakukan dengan membaca materi berulang kali. Menguji pemahaman sendiri, mengulang materi dengan jeda, dan menjelaskan kembali menggunakan kata-kata sendiri merupakan kebiasaan yang dapat membantu memperkuat ingatan.

Secara keseluruhan, ketiga sesi tersebut saling melengkapi. Materi teknologi memberikan gambaran mengenai keterampilan yang dapat dikembangkan, MBKM memberikan wawasan mengenai kesempatan memperoleh pengalaman, sedangkan kurikulum OBE menjelaskan kompetensi yang perlu dicapai selama masa perkuliahan.

Menurut saya, pengetahuan dari workshop ini dapat menjadi bekal untuk menjalani proses perkuliahan dengan lebih terarah, meningkatkan kemampuan secara bertahap, dan mempersiapkan diri menghadapi kebutuhan dunia kerja di bidang teknologi informasi.
